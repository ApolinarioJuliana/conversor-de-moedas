# 💱 Conversor de Moedas

Um conversor de moedas desenvolvido para praticar e aplicar conhecimentos de HTML, CSS e JavaScript, com consulta de cotações por meio de uma API externa.

🔗 **Acesse o projeto:** https://apolinariojuliana.github.io/conversor-de-moedas/

## 📌 Sobre o projeto

O Conversor de Moedas permite informar um valor, selecionar a moeda de origem e escolher a moeda de destino para consultar a cotação e visualizar o resultado da conversão.

O projeto foi desenvolvido como parte dos meus estudos em desenvolvimento web, com foco na prática de JavaScript e na integração com APIs.

## 🚀 Funcionalidades

- Inserção do valor que será convertido.
- Seleção da moeda de origem e da moeda de destino.
- Consulta de cotações por meio de uma API.
- Formatação do resultado de acordo com a moeda selecionada.
- Validação básica do valor informado.
- Exibição de mensagens durante a conversão e em caso de erro.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estrutura da aplicação.
- **CSS3:** estilização e layout responsivo.
- **JavaScript:** lógica de conversão e manipulação da interface.
- **Fetch API:** requisições HTTP para consultar cotações.
- **AwesomeAPI:** consulta de cotações de moedas.
- **GitHub Pages:** publicação do projeto.

## 💰 Moedas disponíveis

- Real brasileiro (BRL)
- Dólar americano (USD)
- Euro (EUR)
- Guarani paraguaio (PYG)

## ▶️ Como utilizar

1. Acesse o projeto pelo link disponibilizado.
2. Informe o valor que deseja converter.
3. Selecione a moeda de origem.
4. Selecione a moeda de destino.
5. Clique em **Converter**.
6. Confira o resultado exibido na tela.
